# Nexauren platform navigation

The public Nexauren shell intentionally exposes only the core platform experiences:

- Home
- Marketplace
- Tools
- Blog
- My Account

Retired sections such as Ranking, Ratings, Community, Workspace, History, Activity, Levels, Forms and Usage are no longer part of the public navigation or homepage experience. Their old route files are kept temporarily to avoid breaking legacy links while the platform is in v0; they are not loaded by the shared shell.

Each future Nexauren experience can provide its own navigation while sharing the same account and authentication system.
